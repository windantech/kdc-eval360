# KDC Impact360 — Eval360 demonstration for Kenya Development Corporation

A demonstration of Eval360 configured as KDC's development impact and performance management
system: strategic KPIs, the investment portfolio, development impact and additionality, SAFER and
DRIVE, ESG, MEL, risk, learning and reporting.

**Published institutional figures** (Strategic Plan targets, SAFER results, DRIVE targets, product
parameters) are drawn from public KDC and World Bank sources, checked on 6 October 2026, and marked
**Public KDC Data** with their source. **Investment-level, portfolio and internal records** are
illustrative and marked **Demo Data**.

## Open it

Open `index.html` (or `kdc_eval360_demo.html`) in a browser — from disk or any static server. Sign
in as any of the twelve demo roles. For a presentation start at **Overview → Demo Walkthrough**.

## Check it

```bash
bash scripts/selftest.sh
```
